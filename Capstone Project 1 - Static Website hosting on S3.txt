Capstone Project -1: Static Website hosting on S3
-------------------------------------------------------------------
Host a static website using S3 with versioning and lifecycle rules.
Configure CloudFront for content distribution.
Map it to your domain


Register domain on namecheap.com/godaddy.com
================================================
1. Open the website in the browser.
2. Type the domain of your choice and click Search button to check availability.
3. If the domain is available, Add to cart and proceed to checkout.
4. Create an account on namecheap.com and proceed to payment.
5. Once the payment is done, the domain is registered for you.


Create Hosted Zone for Domain registered on namecheap.com/godaddy.com
=========================================================================
1. In Route53 page, click on Hosted zone in left navigation pane.
2. In Hosted zone page, click on Create hosted zone.
3. In Create hosted zone page, enter you domain that you registered on namecheap.com/godaddy.com.
4. Give the correct domain name along with the Top Level Domain (TLD).
4. Give some description for it and choose the default selection Public for Type
5. Give a tag for the hosted zone and click on Create hosted zone.


Transfer Domain/DNS management from namecheap.com/godaddy.com to AWS Route53
=========================================================================================
1. In the above created hosted zone page, click on the your domain to open the newly created hosted zone. 
2. In your domains hosted zone page, select the NS record to display the details on the right pane.
3. Open the DNS settings for your domain on the namecheap.com/godaddy.com and change the Nameservers to the values given for the NS record in your domains hosted zone in Route53.
4. Confirm the changes of the Nameservers to the Route53 nameservers provided in the hosted zone to transfer your domain/DNS management from namecheap.com/godaddy.com to AWS Route53.


 Get the SSL/TLS Certificate from Amazon Certificate Manager and validate it
=====================================================================================
1. Open the Amazon Certificate Manager page in new tab and click on Request certificate button.
2. In the Certificate request page, for Certificate type, choose the default Request a public certificate and click Next.
3. In next page, enter your domain along with TLD for Fully qualified domain name.
4. For validation method, choose the default DNS Validation and for the Key algorithm, choose the default.
5. Give a tag for the certificate (optional) and click Request button.
6. A certificate will be issued and will be listed in the List certificate page, click on the certificate ID to open the certificate.
7. In certificate page, in the Domains section, check your domain is added and then click on Create records in Route 53.
8. In Create DNS records in Amazon Route 53 page, verify the domain and click on Create records.
9. You should make sure that a hosted zone is create for your domain and your domain management is in the hosted zone.
10. Go to the your hosted zone page, verify that a new record of type CNAME is added in the hosted zone by refreshing the hosted zone page.
11. Now, refresh List certificate page to verify the status of the certificate should change to Issued.
12. Repeat the point 7 to 11, until the status of cerificate changes to issued.


Create a Static Website Template from tooplate.com:
====================================================
1. Visit tooplate.com website and go to Free HTML Templates.
2. Navigate and download any HTML Template.
3. Go to the Downloads folder and locate the HTML Template .zip file.
4. Extract all the content into a folder.
5. In the extracted content, you will find  the index.html and other content in a folder, keep it open.

Create a bucket:
==================
1. Go to S3 service page and click on Create bucket.
2. In Create bucket page, for Bucket type choose the default selection General purpose.
3. For Bucket name give a unique name globally, like mydevopswebsite and enable Versioning.
4. Leave all other settings at their defaults and then click on Create bucket button.

Upload the files:
==================
1. Open the Buckets page and under General Purpose buckets, click on the newly created bucket.
2. In the newly created bucket's page, under Objects tab, click on Upload button.
3. Go to the HTML template extracted folder which was kept open and contains the index.html.
4. Select all the files and folder along with the index.html.
5. Drag and drop the selected files and folders in the designated area located in the Objects Upload page.
4. Leave all other settings at their defaults and then click on Upload button.


Create a CloudFront distribution that uses an Amazon S3 origin with OAC:
===========================================================================
1. Open the CloudFront console and choose Create distribution.
2. In the Distribution Options, for Distribution name, give a name like mydevopswebsite-distribution.
3. Next choose the option Single domain.
4. For Custom Domain and Tags, you can give a custom domain name and add a tag as per requirement and then click Next button.
5. In  next page, in Origin type section, choose the Amazon S3.
6. In origin section, for S3 Origin, click on Browse S3 button and choose the s3 bucket that you created in above steps.
7. For Origin path, leave the defaults.
8. In Settings section, check the Allow private S3 bucket access to CloudFront option.
9. For origin settings, choose the Use recommended origin settings and click Next button
10. In next page, for Enable Security, in Web Application Firewall (WAF), select Enable security protections.
11. For all other sections and settings, accept the default values. 
12. Choose Create distribution.
13. The CloudFront will update the S3 bucket Bucket policy to allow access the newly create CloudFront distribution.
14. When your distribution is done deploying, the Last modified field changes from Deploying to a date and time.
15. Record the Distribution domain name that CloudFront assigns to your distribution which looks similar to the following: d111111abcdef8.cloudfront.net.


Access your content through CloudFront:
========================================
1. Your distribution domain name might look like this: d111111abcdef8.cloudfront.net.
2. The path to the main page of a website is typically /index.html.
3. Therefore, the URL to access your content through CloudFront might look like this: https://d111111abcdef8.cloudfront.net/index.html.


Update CloudFront Distribution
====================================
-> Before updating DNS, your distribution must be configured to recognize the custom domain. 

1. Add Alternate Domain Names (CNAMEs): Navigate to your distribution settings in the CloudFront Console. Add your domain (e.g., example.com) to the Alternate domain name (CNAME) field.
2. Attach SSL/TLS Certificate: Use the custom SSL certificate, requested via AWS Certificate Manager in the us-east-1 region, to support HTTPS for your custom domain.
3. Note the Distribution Domain Name: Locate the auto-generated domain (e.g., d111111abcdef8.cloudfront.net) for use in the next step. 


Configure Route 53 Alias Record 
======================================
-> Use an Alias record instead of a standard CNAME record. Alias records are free for AWS resources and allow you to map your zone apex (root domain) to CloudFront. 

1. Open the Route 53 Console and select Hosted zones.
2. Select your domain's hosted zone and click Create record.
3. Record Name: Leave this blank for the root domain or enter a subdomain (e.g., www).
4. Record Type: Select A – Routes traffic to an IPv4 address and some AWS resources.
5. Alias: Toggle the Alias switch to On.
6. Route traffic to:
	-> Choose Alias to CloudFront distribution from the dropdown menu.
	->Select your specific distribution from the list. If it does not appear, ensure you added the domain to the distribution's CNAME settings in previous step
7. Routing Policy: Typically set to Simple routing.
8. Click Create records. 


Verification
===============
1. Wait for Propagation: Changes typically take effect within minutes but can take longer depending on TTL settings.
2. Test the Domain: Navigate to your custom domain in a web browser to verify it correctly serves content from your CloudFront distribution.
3. Visit  <domain-name>.<TLD>/index.html
